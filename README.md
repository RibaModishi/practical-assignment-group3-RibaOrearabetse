 Student Projects: Grade Management System & Series Management App
📌 Overview

This repository contains two Java-based projects developed using NetBeans IDE:

Student Grade Management System

An individual project designed to manage student records, calculate grades, and store results efficiently.

The system demonstrates the use of Object-Oriented Programming (OOP) concepts like classes, inheritance, and encapsulation.

Series Management App

A project for managing TV series and episodes, allowing users to add, edit, and delete shows in a structured way.

This application showcases CRUD operations (Create, Read, Update, Delete) and user-friendly interfaces built with Java Swing.

Both projects reflect practical applications of Java programming concepts, aimed at solving real-world problems in education and entertainment management.

⚙️ Technologies Used

Java (JDK 17)

NetBeans IDE

Java Swing (for GUI design)

File Handling (for storing and retrieving data)

📖 Features
Student Grade Management System

Add and remove student details

Enter marks and automatically calculate final grades

Display student reports in a user-friendly table

Simple GUI interface for easy use

Series Management App

Add new series with episode details

Update and delete existing records

Search functionality for quick access

Structured database-like approach with file storage

🚀 How to Run

Download and install NetBeans IDE (https://netbeans.apache.org/
).

Clone or download this repository.

Open the project folder (.zip extracted) in NetBeans.

Clean and build the project.

Run the project and explore the features.
